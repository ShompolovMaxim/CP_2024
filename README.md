Программа позволяет пользователю применять различные нечёткие модели для прогнозирования временных рядов. Параметры нечётких моделей могут быть изменены при помощи гибких настроек, реализованных в программе. Пользователю предоставляется графическая и текстовая (числовая) информация о результатах и точности прогнозирования. 
 
Программа является десктопным приложением и предназначена, в первую очередь, для аналитиков, использующих нечёткие модели для прогнозирования, и исследователей, занимающихся изучением нечётких моделей прогнозирования временных рядов.

Код расположен в директории `FTSPredictionProgram`.
